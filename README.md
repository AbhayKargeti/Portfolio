# Abhay Kargeti

Personal site of Abhay Kargeti, a full-stack software developer based in Faridabad, India.

Built with React, TypeScript, and Vite.

## Run it locally

```bash
npm install
npm run dev
```

`npm run build` type-checks the project and writes the production site to `dist`.

## Update the content

All of the text and links are in `src/content.ts`. To show the resume link, set `resume` in that file.
